# Contributing

Thanks for helping improve the starter.

- Keep sample scenes, prompts, and documentation product-neutral.
- Do not add product screenshots, customer data, API keys, or generated media to commits.
- Keep the default path local-first and usable without paid APIs or MCP connectors.
- When changing the builder, run `npm run check` and capture a few preview frames with `npm run snapshot`.
- Update the README when configuration fields or commands change.

For a small change, open a pull request with a short description of the problem and the local command used to check it.
