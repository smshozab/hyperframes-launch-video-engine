# Instructions for coding agents

- Read `README.md`, `video.json`, and the capture guide before changing a project.
- Treat `video.json` as the source for copy, scene timing, palette, fonts, and capture paths. Rebuild generated HTML with `npm run build`.
- Never invent product UI, screenshots, metrics, customer quotes, or feature claims. Keep missing real captures visibly marked.
- Keep this starter brand-neutral. Use only assets supplied for the current project and do not carry assets or copy over from unrelated products.
- Do not add paid APIs, external media calls, credentials, or MCP dependencies unless the user asks for them.
- Run `npm run check` after changes. Open the Studio preview and get approval before running `npm run render`.
- Keep user screenshots and generated MP4 files out of Git; the repository `.gitignore` already excludes those folders.
